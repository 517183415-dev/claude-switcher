# 后续单元只读交接

本文件保存 audit_runtime 的只读结果。不是实施或验收结论。原定单元顺序保持。

## R04 / F04、F05

user_repairs::repair_legacy_merge_at 在磁盘 Merge 已正确但运行规则未加载时返回 false，阻止 regions/legacy.rs 的必要重载。最小修复让返回值表达 needs_reload；已通过规则仍 false，文件无需改写但运行未加载时 true，保留不写备份语义。

Native::proxy 先调用 execute_app_open（丢弃结果并等待 40 轮），再修 Verge TUN，再等待 40 轮。需要拆开已验证的 open-only 和等待；当前调用改成打开→TUN 修复→单次等待→国家复核。保留 execute_app_open 原契约给 regions.rs 的其他调用者；保留配置提交前、提交后的两个合法 proxy 检查。

隔离测试：FakeAppOpener 和 Runtime 的实际组合入口，统计打开与等待次数、传播打开失败。不要用整个 proxy 的假结果遮住双重等待。预计仅 user_repairs.rs、regions/legacy.rs、proxy_repair.rs。

## R05 / F08、F10

macos.rs read_command 的观察 timeout 是 2 秒；dns_addresses 的 dig 参数却是 +time=3。command_fixture 直接返回，绕过真实等待。保留默认 2 秒，为 DNS 提供可配置内部预算（例如 4 秒）；保留输出限额、UTF-8、超时 kill/wait、退出码及首答案语义。用测试子进程延迟 2.5 秒输出合成答案，不调用 dig 或真实 DNS；同时验证超时与取消回收。timeout 不包括后续 kill/wait，不能宣称总调用绝对墙钟上限。

pinned_routes.rs propose 仅精确识别 prepend-rules:。带注释/尾空格及 inline 值会新增重复顶层键；两个既有顶层键未拒绝；无目标键且有 --- 时会把规则放到文档头前。CRLF 和嵌套同名键已有正确分支。保留这些分支及嵌套管理标记拒绝。

最小文本修复：识别顶层空白/注释并保留原行；拒绝不支持的 inline、重复键和多文档，避免输出坏 YAML；单文档头后插入新块。成功测试断言规则保留、键唯一、换行不变、可解析、幂等。拒绝测试断言不写入。不新增依赖或完整 YAML 重写框架。预计仅 macos.rs、pinned_routes.rs。

## R06 / F06

安装 cli_shim 当前原样 exec Rust --edition，不做输出协议转换。建议由 shim 显式注入 legacy 模式；直接二进制维持现代协议，显式 JSON 可走现代结果。

旧 status stdout 是 current=... hasA=0/1 hasB=0/1，无归属 none，退出 0。旧 check 成功 OK:<ip>[|警告]，失败 FAIL:<原因>，0/1。旧 switch 有明细、NOTE/INFO/OK，门禁/退出失败 1、目标非法 2、成功 0。旧 fix 输出 FIX:进度；前置门禁 1，旧脚本走到末尾 echo 则 0（可能中途失败）。不应主张所有旧错误在 stderr，也不应为兼容把修复部分失败伪装成功。需要在 R06 明确这个退出码偏差。

现代 status/switch 是 JSON；fix 是多条 JSON 行。现代业务未完成一般 2，stderr 为空。repair_cli.rs 当前直接打印，因此若要 legacy fix 不泄露预览 JSON，该文件必须进入本单元范围；总数仍不超过五文件。

成功 check 的出口/警告应来自内部检查结果，不能解析中文 reason 或为输出兼容新增网络查询。F01 的未知账号归属保持未知，不因显示兼容写 current 或初始化为 A。

合成回归应捕获 stdout/stderr/code，注入检查、账号结果与实际阶段事件；避免真实 switch/fix。shim 用临时假程序验证参数和输出/退出码透传。不要直接跑整个 checks_cli：其中诊断测试会连接本机回环。新增过滤测试与现有 status_is_readonly / invalid_arguments 可离线执行。
