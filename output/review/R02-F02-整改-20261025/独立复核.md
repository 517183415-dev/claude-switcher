# R02 / F02 独立复核

复核角色：独立只读代码审查。审查者未编辑文件、未运行测试、未访问真实系统服务或账号。

## 发现与修复

1. 删除前未统一验真全部完成备份。现在验证内容、权限及 root 所有者，并在停止进程前再次验证。
2. 已持久保存恢复身份后仍能使用恢复中豁免。现在禁止豁免，并清除恢复中标记。
3. 旧 root 服务扫描阻挡缺失脚本的合法卸载。新卸载的旧版扫描只负责用户更新服务。
4. 已注册服务缺少恢复必需文件仍可停止。现在预览直接拒绝；未注册的缺失对象仍可卸载。
5. root 文件复制中断会留下半个正式文件。现在在私有暂存区复制和验真，再独占原子发布。
6. 恢复校验后出现同字节替换，可能被收尾重新认领。现在绑定已验证或本次发布的设备及 inode，并在最终快照再次比较。
7. 已恢复文件再次被外部删除，旧删除标记可能允许重建。现在保留 journal 并拒绝。

大二进制修正仅用于 helper 和 guardian。其他 `small_file` 调用仍保留 1 MiB 上限。

## 最终意见

审查者结论：COMMENT。本轮有界复核没有剩余代码阻塞。两项恢复身份窗口已经闭环。
