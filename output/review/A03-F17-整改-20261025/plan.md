状态：只读事实与实施合同已定义，产品代码及动态验证尚未完成。基于本地 audit_ads 独立核实，由 root 归档。每组不超过五个源文件；等待 A01 释放写入文件、A02 冻结终态结构后实施。

## 容量和引用合同

保留历史256条、登记素材128个上限。恰好满额的状态可以打开，也必须可以进入整理。默认保留最近128条历史。N表示最终保留总数，包含preview/production current所对应的固定历史记录。先固定这些记录，再按追加顺序补足最近N条；N小于固定记录数或大于256时拒绝。

保护集合为草稿、pending、保留历史、同一发布树锁内认证的两个current、A02保留终态证据，以及未释放恢复检查点的素材引用。过期、disabled或排期结束均不是删除依据。有水位却缺current、坏签名、范围错误、读取异常或current引用未登记素材时拒绝回收。pending存在时允许预览，但第一版拒绝提交整理。

预览显示保留及移除历史、每项素材保留原因、候选文件及字节数、逻辑容量释放量和阻断原因。选择全部保留明确显示不释放历史容量。序号水位不随裁剪下降，不修改草稿、pending或两个current。

## 两次确认和事务顺序

```text
选择N → 具体差异预览 → 第一次确认
  → 同锁复核state/current/证据摘要
  → 单批有界恢复检查点
  → 原子提交历史与素材索引
  → 明示文件尚未删除
  → 重新预览具体文件 → 第二次确认
  → 同锁重验引用和文件身份 → 逐项回收
```

单批检查点保存旧state、候选清单和执行基线，不复制全部素材。只允许一个未结束批次，检查点数量和字节均有界。不能要求全量备份成功；坏素材或JSON膨胀导致64MiB导出失败时仍应有整理出口。

预览后generation、state、任一认证current或ETag、pending、A02证据引用、N或候选集合改变时拒绝旧预览。索引提交保持密钥、generation及水位。提交后目录fsync失败时读取磁盘校准内存，继续报告耐久性错误，不盲目回滚。

第二次确认说明回收后将失去本批完整本地撤销能力。重新被引用的候选跳过并报告。只处理本批固定assets目录内明确登记的普通文件，验证无符号链接、无异常硬链接、所有者、权限和文件身份。禁止递归删除、按时间盲删、顺带删除未知generation/备份/其他资料。

逐文件回收可中断。失败后保留准确候选，重试重新验证；已确认属于本批且已不存在的文件可视为已完成。进度写失败不等于全完成。A02终态证据不计入N，引用持续受保护；淘汰必须单独出现在显式整理预览，不因历史裁剪而顺带消失。
