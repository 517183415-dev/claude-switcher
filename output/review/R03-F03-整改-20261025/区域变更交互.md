# R03 只读交互核查

来源：audit_install 对当前源码的只读核查；尚未实施或运行新测试。

1. Rust set-region 先保存 config.json，再用管理员 sed 改 watchdog TARGET。当前 sed 生成无引号赋值；它不更新 CLI shim 或安装代际归档。
2. Python verify_public 读取当前 JSON 目标，再比较带引号的 watchdog_payload。CLI 验证则从当前 shim 自身 literals 重建；旧 literals 不在该路径强制等于当前 JSON。
3. R02 plan_uninstall 要求当前 root 脚本 SHA256 等于不可变安装代际 watchdog-new-script。合法 TARGET 变化会触发此处拒绝，即使先修复引号。
4. 最小合同需要保留不可变代际基线，只允许唯一且校验过的 TARGET 字段变化；其余字节、固定路径、root:wheel、权限保持严格。公开 verify 要求 TARGET 等于当前 JSON；不能仅用用户配置或最新模板代替代际归属依据。
5. 卸载 preview 仍记录地区更新后的实际 sha/dev/ino；删除前复查，回滚恢复该新 TARGET。不可恢复安装初始旧 TARGET。既有 R02 snapshot、holding、candidate 与终态合同必须保留。
