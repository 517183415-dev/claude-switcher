## 问题与修复

广告请求失败后，旧逻辑从请求开始时间计算退避。请求开始于合成时间 1000、失败于 1120 时，旧代码把下一次检查设为 1060，导致检查时间已过。正式 HTTPS 客户端连接本机非 TLS 对端，合成时钟复现此问题；`slow-request-before-fix.log` 保留失败断言。

修复后，失败时再次采样时钟，并从失败时间计算退避。结束时钟不可用时，使用请求耗时向上取整作为备用时间。备用时间依赖进程的单调时钟；未验证真实休眠期间的行为。
