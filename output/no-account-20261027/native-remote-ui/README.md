# 产品页面远程配置验证

2026-10-27 在隔离 HOME 和 Seatbelt 内构建产品 Svelte 页面，并在真实 WKWebView 中操作。测试专用构建只模拟 `workspace_snapshot` 和 `check_environment`。其他命令通过正式 Tauri IPC、权限配置、Publisher 和合成 MemoryVault 执行。

页面完成本机读取、预览和正式渠道保存、预览切回本机及选回保留目标。6 次相关发布接口响应和 2 个检查点通过。保存后，凭据输入框清空。检查确认合成凭据未出现在响应、运行日志和测试业务目录。[机器回执](r5/receipt.json)记录输入与二进制哈希。

最初测试脚本试图替换 Tauri 的只读 `invoke`，拦截没有生效。对照测试确认原生窗口可运行；[诊断回执](r4/heartbeat.json)确认页面和测试脚本均已加载。测试构建改用专用模块包装后通过；`tauri-shim.test.mjs` 还验证只读接口保持原样，普通发布调用转发，模拟只覆盖两个启动命令。该问题属于测试夹具，不能据此判定产品存在同一缺陷。

本结果不证明默认 Keychain、应用进程重启、真实 R2/CDN、线上发布或其他产品页面。WebKit 日志中的用户目录访问错误来自隔离策略。注册、部署和付款继续暂停；SwiftUI 重写仍在现有任务最后。
