# 单槽暂停和历史恢复：隔离原生窗口验证

一次真实 WKWebView 场景通过。独立测试前端使用产品 IPC 注册表、普通 ACL、正式 Publisher 处理函数、合成 MemoryVault 与本机对象存储。资料、密钥、图片和域名均为合成值。未使用真实账号、默认 Keychain 或远程服务。

13 次 IPC 响应覆盖：建立签名密钥、三槽各两期、初次发布、单槽暂停及发布、全暂停及发布、不存在的历史拒绝、历史恢复及显式发布。8 个宿主快照核对：

1. 单槽暂停保留该槽的排期以及另外两槽的完整数据。
2. 暂停和历史恢复只写草稿，发布前公开文件不变。
3. 不存在的历史返回错误，状态和公开文件不变。
4. 宿主使用 Node crypto 独立验签 4 个不可变正式版本，核对 current 与版本递增。恢复后的广告位与最初发布一致。

代码只增加测试工具，复用 native-publisher/runner.py 的隔离、构建、回执和清理流程。r1/build.json、r1/inputs.json、r1/webview.json、八个快照及 r1/receipt.json 为实际执行证据。r1/tmp/business-root 为合成状态和签名结果；Git 不保留 POSIX 私有权限，实际权限由测试期间检查。二进制与编译中间文件不纳入 Git。

编译通过，JavaScript 语法和 Python 编译检查通过，原生场景通过。未重跑既有完整套件。该证据不证明未经修改的产品前端、OS 进程重启、默认 Keychain 权限、真实 R2/CDN 或 AD-07 全部分支；真实账号与长时间运行另行验收。
