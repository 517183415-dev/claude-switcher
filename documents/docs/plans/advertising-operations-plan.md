# 广告管理：日常操作说明

版本：v1.2。产品要求见 [PRD](PRD-Rust双版本产品-v1.2.md)，协议和验收见 [工程文档](工程执行文档-Rust重写-v1.2.md)。

首版在 Personal 的“运营 → 广告管理”提供以下流程。

## 1. 发布广告

1. 选择美国家庭宽带、注册好的账号或 KYC 服务。
2. 编辑商家、文字、图片、链接和起止时间，保存草稿。
3. 用同组件预览，发布到 preview 检查。
4. 查看变更摘要后发布 production。
5. 等待公开入口回读，查看成功版本与发布时间。

```text
编辑 → 预览 → 签名发布 → 公开回读 → 客户端刷新
```

每位支持当前一期和下一期。编辑器默认使用本机时区，保存为 UTC。三位各自开关、排期和暂停。

## 2. 更新、暂停和恢复

| 操作 | 结果 |
| --- | --- |
| 更新商家、文案、图片或链接 | 发布新内容序号；软件版本保持原值 |
| 安排下一期 | 客户端按已签名的 UTC 排期切换 |
| 暂停一位或全部 | 发布新序号；在线客户端下一次成功刷新收起 |
| 恢复历史 | 检查排期和素材后，用历史内容发布更高序号 |
| 恢复备份 | 解密运营备份，回读当前正式序号，再补素材并发布 |

健康且连续在线、首轮请求成功时，目标20分钟内采用。离线展示采用24小时缓存、广告结束、清单到期三者最早期限。页面明确显示这两类状态。

## 3. 首次配置

需要本人控制的 HTTPS 内容源、具备条件写入的静态存储、广告签名密钥，以及三类商家素材。凭据通过安全输入进入本机密钥存储。

首版只接入一个已验证存储。内容源、公钥和模板变化走软件发布。日常内容在广告管理页完成。

Public 包保留读取与展示。广告全部关闭后停止内容请求。Personal 普通启动默认关闭展示，运营网络请求由相应操作触发。
