# GitHub 源码交付与本地安装补充

日期：2026-10-23。适用交接：CS-RUST-20261022-R4。

## 用户决定

用户明确选择“提供源码和本地构建/安装脚本”，不购买 Apple 开发者会员，也不要求正式二进制发布。本补充只修订 v1.2 的交付与安装身份前提。四包、12 项任务、37 项验收 ID 保留。广告后置；无障碍专项按用户指令跳过。普通功能和权限验证继续。

## 本次实现

1. 安装记录使用 schema2 和显式信任枚举。DeveloperId 保留 Apple anchor/Team/identifier。SourceLocal 保存本次安装 generation、GUI/guardian/helper 的精确 CDHash。Bundle ID 从固定角色导出。旧 schema1 开发记录拒绝并提示重新安装，不隐式降级。
2. 本地构建使用 ad-hoc 签名与 Hardened Runtime。仅支持本机原生单架构。管理员批准本地工件后，在 root 私有 staging 再次验证完整签名、哈希与固定清单。源码和密钥不会自动上传。
3. 本地安装必须统一处理 App、helper、guardian、服务模板和安装记录。使用生命周期锁、root 操作锁、持久阶段、原件备份、健康验证、恢复。未完成事务保留现场。普通 XPC 不提供登记新 pin 的接口。
4. XPC 两端在连接激活前设置系统 peer requirement。helper 接受固定角色 requirement 的并集，再保留消息级角色、owner、会话与序列验证。SourceLocal 没有独立 Installer 客户端身份，拒绝该角色。首次握手不携带秘密或管理员凭据。
5. Public 的原签名更新实现保留。SourceLocal 升级通过拉取源码、重新构建、本地管理员安装登记新指纹。没有可信更新源时不声称自动安装可用；不新增自动执行远端源码的构建服务。

```text
源码 → 普通用户构建 → 查看安装计划 → 管理员本地安装
                                          ↓
                           root 暂存验证 → 备份 → 替换
                                          ↓
                           新服务健康 → 提交 / 恢复
```

## 文件归属与验证

- Root：domain 安装合同、集成、规格和验收记录。
- 身份执行者：helper XPC/原有 root 操作身份、core 安装身份/guardian/lifecycle/更新门禁。
- 安装执行者：本地构建与安装脚本及隔离安装事务测试。
- 独立复审：权限边界、安装中断和指纹替换检查。

先运行安装合同、helper、guardian、install、lifecycle 的定向测试，避免完整 core 测试触发假 Claude.app。构建两版并验证实际签名与错误 pin 拒绝。管理员安装、真实双进程 XPC、真实账号和长期观察单独取证。隔离 PASS 不替代真机验收。保留 r9 工件和证据；本次生成新候选。
