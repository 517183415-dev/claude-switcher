我关心的是“这份软件有没有坑我的可能”。请聚焦下面两条主线。代码风格、性能及普通业务问题只在影响这两条主线时展开。

| 资料外传 | 是否读取账号档案、聊天、Cookie、令牌、密码、Keychain、浏览器资料、SSH 密钥、剪贴板或用户文档？读取结果流向本地何处或远端何处？ |
| 远程修改 | 谁能通过更新、下载文件、远程配置、广告内容、命令拼接、WebView、后台任务或管理员 helper 改变本机行为？触发条件、权限和目标文件是什么？ |

对每个外联点，建立一行数据流记录：

`发起文件与行号 -> 本地读取的数据 -> 请求字段 -> 目标域名/地址 -> 响应用途 -> 本地写入或执行 -> 权限与触发方式`

特别核对这些问题：

1. 请求是否携带账号内容或凭据？代理认证发送给谁？接收方是否只获得连接元数据？代码中的域名是实际请求目标、代理规则条目，还是说明文字？

每项发现至少给出：原始文件与行号、可复核数据流、接收方或控制者、触发条件、实际权限、证据类别、影响、置信度，以及最小处置建议。
