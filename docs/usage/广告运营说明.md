# 广告运营说明

适用规格：[PRD v1.2 §5](../plans/PRD-Rust双版本产品-v1.2.md)、[工程执行文档 v1.2 §5](../plans/工程执行文档-Rust重写-v1.2.md)。当前为开发候选。本轮使用真实本机私有目录运营，不需要 R2/S3、云域名或云存储凭据。真实密钥和本机发布验收以运行结果为准。

## 1. 入口与材料

只有 Personal 提供“广告运营”。Public 只读取、验签和展示内容，构建中移除运营页面、发布命令和写入能力。

草稿、素材和发布内容保存在本机。预览区与正式区使用独立目录。本机发布需要广告签名密钥，并验证签名及素材回读。它不会向其他用户远程投放；远程托管未启用。

点击“创建本机广告签名密钥”才会在 Keychain 创建私钥。本机客户端使用公开验证材料；私钥保留在本机受控密钥存储。不要把凭据写进草稿、日志或截图。广告密钥与软件更新密钥分别管理。

## 2. 三位六期

| 固定广告位 | 内容 |
| --- | --- |
| 美国家庭宽带 | 独立商家、素材、链接和排期 |
| 注册好的账号 | 独立商家、素材、链接和排期 |
| KYC 服务 | 独立商家、素材、链接和排期 |

每位最多保存当前一期和下一期，合计最多六期。切换广告位不覆盖其他位。每期填写商家名称与标识、标题、说明、按钮、HTTPS 地址、图片、起止时间和开关。同一广告位的有效排期不能重叠。

时间以 UTC 保存。编辑器默认使用本机时区，可切换为 UTC。素材仅支持静态 PNG/JPEG；归一化后单张不超过 1 MiB、200 万像素。格式混淆、动画、超限或无效图片会被拒绝。

客户端使用广告位开关控制读取和展示。运营草稿中的开关控制发布内容，两者分别生效。

## 3. 预览与发布

1. 选择广告位，编辑并保存本地草稿。
2. 使用共用广告卡片预览当前一期、下一期和两种窗口尺寸。
3. 点击“发布到本机预览”，核对完整内容、图片及规范化商家主机。预览区不改变正常广告区。
4. 明确确认后点击“发布到本机正式”，等待本机签名内容及素材回读。
5. 查看本机发布历史。只有回读通过，才视为发布完成；本机两个发行的广告区读取正式区。

```text
本机草稿 → 共用预览 → 本机预览区 → 本机正式区
                                      ↓
                              签名回读 → 本机发布历史
```

两个环境使用独立目录。本机发布写入清单、图片和签名，不需要云鉴权，也不附加账号、设备或代理资料。遇到版本冲突先重新读取、合并；结果未知时先回查，避免重复覆盖。

日常商家、图片、文案、链接和排期沿用当前软件版本。内容源、公钥、模板或不兼容的数据结构变更需要软件发布。

## 4. 暂停、刷新与点击

“暂停此位”“全部暂停”和“恢复为新草稿”先建立更高内容序号。仍需预览并发布到本机正式区，才会影响本机客户端。历史和关联素材至少保留 90 天。

本机正式发布后，在广告展示设置中开启对应广告位，再点击“刷新广告内容”。后端限制手动刷新间隔为 30 秒，并合并并发刷新。本轮不提供远程传播承诺。

离线展示在“最后成功读取加 24 小时、广告结束、清单到期”三者最早时刻截止。签名失败、过期或超限时，仅使用仍有效缓存或本地占位。时间异常的处理见[恢复说明](Rust恢复说明.md)。

商家或规范主机变更后的首次打开，需要确认后端核验的目标。链接由系统浏览器打开。首版没有点击或曝光统计。全部广告关闭时，不读取广告内容。本机发布不发送云存储请求；主动打开商家链接仍由系统浏览器联网。

## 5. 加密备份

在“加密备份与恢复”输入至少 12 个字符的口令，再导出加密备份。通过“打开备份目录”找到文件，并保存到本人控制的位置。备份口令与备份文件分别保管。

备份包含草稿、历史、素材索引和加密密钥。恢复前保留当前状态和现有备份，再选择备份文件并输入口令。恢复后先回读本机正式内容序号，再补齐缺失素材并发布下一版本。备份恢复不会自动启用远程托管。
