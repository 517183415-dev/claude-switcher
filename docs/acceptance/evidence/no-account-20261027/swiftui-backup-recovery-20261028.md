# 发布提示与备份恢复回归（2026-10-28）

范围：基于 `f3e582be` 的本轮源码改动；macOS 27.0.1，arm64。窗口测试使用隔离目录和合成内存密钥库，并禁止网络。测试构建启用 `ipc-business` 夹具；它不是此前构建的普通产品包。

## 结果

1. 改动前，4 项状态回归出现 6 处断言失败；读取重试测试又发现 4 处失败。恢复与刷新同时失败的回归发现 6 处断言失败；文件读取失败提示的回归发现 3 处失败。修复后 Swift 测试共 28 项通过。回归覆盖恢复、暂停、导出、文件读取错误、恢复刷新重试和 4 类读取重试。
2. 隔离窗口使用有效的 64 MiB 加密备份，经过 Swift 文件读取、`PublisherModel`、WebView 和 Rust 正式恢复处理函数。无效备份先被拒绝且草稿不变；有效备份恢复草稿、不自动发布、解除恢复锁，并可再次导出。备份包含正常小型快照和空白填充，不代表 64 MiB 真实素材。此大文件测试早于本轮恢复错误保留修复。
3. 后续隔离窗口测试使用正常导出的小备份完成同样的恢复闭环。它晚于恢复错误保留修复，早于文件读取错误提示修复。两次窗口测试的源码哈希保留在各自回执中。
4. Rust 夹具文件的格式检查通过。此前已通过的 Rust 全套、双版本 Clippy 与产品包检查没有重复运行；此前的普通产品包不包含本轮状态提示修复。
