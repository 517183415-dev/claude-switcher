# 远程发布请求隐私隔离测试

Personal 发布器使用真实 AWS S3 SDK，向仅监听回环地址的模拟对象存储发布合成广告。测试使用独立进程、临时 HOME、内存密钥库和虚构资料。系统沙箱禁止公网、真实账号目录和默认 Keychain 访问。

测试先用正向对照确认模拟服务能记录请求路径、查询参数、请求头和完整请求体。随后检查实际发布、匿名回读及接收端验签的全部请求。合成账号、Cookie、代理文件、代理地址和凭据、写入密钥，以及签名种子的原始、JSON、十六进制和 Base64 形式均未出现。写入用的合成访问密钥 ID 允许出现在认证头，其他位置不得出现。测试还确认了广告素材和已签名版本实际经过发布及接收流程。

[定向测试日志](../../../../output/no-account-20261027/r2-privacy-wire-20261028/test-cached.log)：1 项通过；该项内部确认隔离子进程的测试确实运行并通过。严格 [Clippy](../../../../output/no-account-20261027/r2-privacy-wire-20261028/clippy.log) 和修改文件的格式检查通过。日志中有既有 ts-rs 属性解析提示。测试源码 SHA256：`3544ea2f4db928583651f0e5ff8e80e1ad330114ef2216552e1808e55a6d500b`。模拟服务只保留本次进程内的请求数据；回执和日志不保存请求正文。

第一次隔离构建因 Cargo 缓存路径变化而不必要地重编依赖，约 65 秒后主动中止，尚未运行测试。随后改用原缓存路径；定向测试含构建耗时约 150 秒。没有重复执行已通过的测试。

此结果只覆盖本测试注入的标记和所执行的请求路径。SDK 的目标地址和公开读取地址指向回环 HTTP；接收端测试也将源地址映射到回环。该测试不验证生产 HTTPS、重定向、云端签名认证、真实 R2/CDN、真实账号、默认 Keychain、普通 App 窗口或长期运行。它不代表完整 PR-01 或 AD-10 通过。注册、部署和付款继续暂停。
