# 独立密钥库的远程配置跨进程测试

本次测试调用实际 `Publisher` 和 macOS Keychain 接口。它使用临时创建的独立密钥库、合成签名密钥和两套合成远程配置。测试未访问用户默认密钥库中的凭据，也未连接远程服务。

写入进程保存预览与正式渠道配置后退出。另一个进程重新打开发布器，读回完整的非秘密配置。测试还验证：信任文件缺失时，重新创建签名密钥会失败，并保留原有密钥和凭据。

一个显式启用的顶层测试通过；写入和读取是该测试启动的两个子进程，不另计测试数。结果记录显示两个进程均正常退出，配置读回和旧密钥保护均通过。独立密钥库及其测试条目已清理；默认密钥库及搜索列表的前后快照一致。Rust 测试程序离线编译、定向严格 Clippy 和格式检查通过。

原始结果位于 `output/no-account-20261027/native-remote-process.Z1JOz9/`，包括 `native.log` 和 `synthetic-state/` 下的结果记录。测试基于提交 `2e9edfbb`，并增加了测试代码。

该结果不证明普通 App 或 SwiftUI 重启后的读取，不证明用户默认密钥库权限，也不证明真实 R2、CDN、设备重启或线上更新。此次没有修改产品运行代码；已有候选包无需因此重建。注册、部署和付款继续暂停。
