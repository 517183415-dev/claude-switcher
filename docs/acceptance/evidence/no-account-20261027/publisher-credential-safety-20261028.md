# 发布密钥和恢复配置的隔离回归

## 修复

- 信任文件丢失但密钥库条目仍存在时，新建发布密钥使用只创建操作。旧条目存在时操作失败，原凭据保持不变。
- 已有信任公钥或发布目标、但密钥库条目缺失时，读取远程配置返回错误。全新发布器仍返回空配置。
- 远程配置读取失败，或备份、归档恢复后，SwiftUI 清除旧配置。用户须重新读取，才能继续编辑。

三个问题均先用隔离测试复现失败，再验证修复。Rust 回归使用内存密钥库和合成目标；Swift 回归使用模拟桥接。失败及通过日志保留在 `output/no-account-20261027/key-create-isolated/`。
