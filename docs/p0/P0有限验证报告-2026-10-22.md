## 3. 原生和账号依赖证据

C XPC 的 peer signing requirement 在 SDK 中标注 macOS 12 起可用。NSXPCConnection 对应要求和 SMAppService 标注 macOS 13 起可用。Objective-C availability 编译检查退出码为 0。

Rust 探针通过字典往返、合法签名要求设置、非法要求拒绝和临时签名自身校验。临时签名受到 Apple anchor 要求拒绝。合成 XPC 对象缺少真实发送者身份，返回预期错误。

这些操作使用当前用户权限。真实接收端消息身份、Team ID/Bundle ID 矩阵、服务注册、授权取消、helper 版本交接仍须集成验证。

当前 Claude 为 3.1623.0，Bundle ID 为 `com.anthropic.claudefordesktop`。公开签名校验通过。公开 entitlements 包含 WebAuthn、硬件密钥及 Microsoft 身份相关访问组。应用二进制出现 safeStorage/keytar 字样。实际 Keychain 项名与迁移依赖继续保持 WAIT。

只读目录清单记录了活动资料和 A/B 档案的顶层属性。文件内容、登录令牌和账号秘密未纳入报告。
