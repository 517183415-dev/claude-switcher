# 独立 Keychain 原生验证

1. Apple 开源 StorageManager::shouldAddToSearchList 明确排除普通私有 Keychain。预探针已在原隔离策略内完成私有文件创建、限定查找、删除，前后默认库与搜索列表一致。禁止使用 login.keychain 或系统 Keychain 路径，禁止设置默认库与搜索列表。
2. 保留正式应用默认 Keychain 行为。KeychainVault 增加私有位置字段，只有 cfg(test) 构造器可指定独立 Keychain；没有 IPC、环境变量或配置入口。创建仍使用同一 SecItemAdd 独占逻辑；编码、校验与业务恢复共用。限定库的读写通过 SDK 显式参数完成，默认库读写保留既有 SDK 路径。
3. 沿用现有忽略测试和显式启用保护。在全新 output 私有目录创建两个独立库，使用同一服务与账号放置不同内容，验证创建/更新/查询/清理的跨库隔离，再验证重复创建、真实双线程竞争、坏口令、恢复旧密钥与代次保护和同进程重新打开。正常与 panic 均清理条目及私有库；前后核对默认库及搜索列表。
4. 先保留前阶段失败证据。此次不将独立库通过外推为用户默认库权限、WebView 成功业务或 OS 进程重启。必要时补纯逻辑回归；改动后定向测试，阶段末集中一次 Personal 主程序验证、Public 编译与 Clippy/格式检查。不要重跑未受影响前端和系统验收。
5. 更新代码图谱、PRD、覆盖索引与本地 Git。UI 保持最后，保留当前布局和非蓝紫色配色；注册、部署、付款暂停。
