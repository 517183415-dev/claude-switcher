# 多目标清理接线

范围：本地实现与合成数据测试。不注册、不部署、不付款，不启动子代理。

当前缺口：配置槽只保存当前 R2 目标。更换配置会丢失旧目标访问资料，但旧目标账本仍然存在。清理无法完成全部目标核对。

```text
渠道配置 → Vault 内目标配置表 → 目标身份与账本覆盖核对
                                      ↓
全部目标锁 → 认证 current → 索引整理 → 单独确认文件回收
```

1. 先用回归测试复现更换配置丢失旧目标资料。
2. 将渠道凭据升级为有界目标配置表。兼容旧格式，保留既有目标，显式选择本地不删除远程资料，同一目标轮换只替换其凭据。
3. 根据全部账本核对配置覆盖。缺失时提示补齐，损坏时拒绝操作；清理缺少完整来源时仍停止，不猜测来源，不改变发布状态。远程锁未接通前不开放产品清理。
4. 覆盖重启、加密备份、坏配置、容量、渠道隔离、写入失败和配置覆盖。阶段结束集中运行受影响套件，更新代码图谱、PRD 与本地 Git。

责任：`publisher/connection.rs` 保持配置入口；新增 `publisher/connection/registry.rs` 管理格式与完整性；`connection/tests.rs` 覆盖产品业务，配置表格式边界也纳入该业务测试文件。复用现有 Vault、16 KiB 凭据上限和目标容量，不增加依赖。

本阶段进展：目标配置保留、无秘密配置清单、旧账本缺失提示、Personal 目标回切及回归已实现。配置表是远程锁接线前置；全部目标锁与产品清理装配尚未完成。
